    완전 무료

    광고도, 추적도, 계정도 없습니다. 데이터는 오직 이 기기 안에만 저장돼요.

    자주 묻는 질문

    브라우저를 닫아도 9시에 알림이 오나요?

    기기·브라우저에 따라 달라요. 설치형 PWA(예: Chrome)는 주기 백그라운드 동기화로 닫혀 있어도 알림을 시도하지만, 100% 보장되는 알림은 서버와 웹 푸시가 필요합니다. 아침에 기기를 켜서 쓰신다면 이 정적 버전으로 충분해요.

    왜 오늘은 다른 사람과 같은 명언이 나오나요?

    명언은 랜덤이 아니라 날짜를 기준으로 결정적으로 선택됩니다. 그래서 같은 날 접속하면 누구나 같은 3개를 보게 되고, 자정이 지나면 새 명언으로 바뀝니다.

    내 데이터는 어디에 저장되나요?

    알림 켜짐 여부 같은 최소한의 설정만 브라우저의 로컬 저장소에 보관됩니다. 서버로 전송되는 개인정보는 전혀 없습니다.

    명언을 직접 추가할 수 있나요?

    네. 오픈된 정적 프로젝트라 quotes.js의 목록에 { text, author, cat } 형식으로 추가하면 바로 반영됩니다. 자세한 내용은 저장소의 README를 참고하세요.

    오늘도 좋은 하루 되세요 🌅
