# GLOWLAB — 메디큐브 스타일 뷰티 커머스 💙

피부과학(더마) 뷰티 브랜드를 위한 **홈페이지 + 제품 상세페이지** 데모입니다.
메디큐브 같은 국내 뷰티 커머스의 구성을 참고해, **순수 정적 HTML/CSS/JS**로 만들었습니다.
서버 없이 **GitHub Pages** 등 정적 호스팅에 바로 배포할 수 있습니다.

> ⚠️ 실제 브랜드가 아닌 데모용 샘플입니다. 제품·수치·후기는 예시입니다.

## 📄 페이지 구성

| 페이지 | 파일 | 내용 |
| --- | --- | --- |
| **홈** | `index.html` | 공지바 · 헤더 · 히어로 배너 · 카테고리 · 베스트 랭킹 · 디바이스 배너 · 스킨케어 · 혜택 · 리뷰 · 뉴스레터 · 푸터 |
| **상세페이지** | `product.html` | 갤러리 · 구매 패널(옵션/수량/가격) · 스티키 탭 · 긴 상세컷(성분·비교·사용법·리뷰·Q&A) · 관련 상품 · 모바일 구매바 |

## ✨ 주요 기능

- **반응형** — 데스크톱 4열 그리드 → 모바일 2열, 모바일 햄버거 메뉴/드로어.
- **상세페이지 상호작용**
  - 썸네일 갤러리 전환
  - 옵션 선택 + 수량 스테퍼에 따른 **실시간 금액 계산**
  - 스크롤 위치에 따라 활성화되는 **스티키 탭(스크롤스파이)**
  - 모바일 하단 **고정 구매 바**
- **장바구니 카운트** — `localStorage`에 저장되어 새로고침해도 유지.
- **위시리스트 토글 · 토스트 알림 · 뉴스레터 폼**(데모 동작).
- **사진 느낌의 제품 렌더** — 제품별 이미지를 `assets/`에 **SVG 렌더**로 담아 (앰플·패드·세럼·크림·토너·디바이스·선케어·마스크팩) 외부 이미지 없이도 실제 상품 이미지처럼 보이고 오프라인에서 동작합니다.

## 🎨 커스터마이징

- **색상/토큰**: `styles.css` 상단 `:root` 변수 (`--blue`, `--pink`, `--radius` 등).
- **상품 목록**: `main.js`의 `PRODUCTS` 배열을 수정하면 홈 그리드가 자동 갱신됩니다.
- **상세 내용**: `product.html`의 각 `.detail-block` 섹션 텍스트를 교체하세요.
- **실제 사진으로 교체**: `assets/`의 SVG 대신 실제 상품 사진(jpg/png)을 같은 파일명으로 넣거나,
  `main.js`의 `img` 경로와 `index.html`·`product.html`의 `<img src>`를 여러분의 이미지 파일로 바꾸면 됩니다.
  (정사각형 이미지를 권장 — 카드/갤러리가 `object-fit: cover`로 채웁니다.)

## 🚀 실행 방법

정적 파일이라 로컬 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 📦 배포 (GitHub Pages)

1. 이 브랜치를 푸시합니다.
2. GitHub 저장소 **Settings → Pages**에서 브랜치를 소스로 지정합니다.
3. 발급된 `https://<사용자>.github.io/<저장소>/` 주소로 접속합니다.

## 📁 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 홈페이지 |
| `product.html` | 제품 상세페이지 |
| `styles.css` | 전체 스타일 (디자인 토큰, 반응형) |
| `main.js` | 공용 스크립트 (그리드 렌더, 갤러리, 수량/가격, 탭, 장바구니) |
| `assets/*.svg` | 제품 이미지 렌더 (사진 대신 사용, 교체 가능) |
| `icon.svg` | 브랜드 아이콘 |
| `manifest.webmanifest` | PWA 매니페스트 |
