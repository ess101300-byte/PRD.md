# 오늘의 명언 · 아침 9시 알림 🌅

매일 아침 **오전 9시**에 오늘의 명언 3개를 브라우저 알림으로 받아보는 정적 웹앱(PWA)입니다.
서버가 필요 없어 **GitHub Pages** 같은 정적 호스팅에 바로 배포할 수 있습니다.

## ✨ 기능

- **오늘의 명언 3개** — 날짜를 시드로 결정적으로 선택되어, 같은 날에는 항상 같은 3개가 표시되고 매일 자정에 새로 바뀝니다.
- **9시 알림** — "알림 켜기" 버튼으로 권한을 허용하면 매일 오전 9시에 명언 알림이 표시됩니다.
- **PWA** — 홈 화면에 설치하고 오프라인에서도 사용할 수 있습니다.
- **내장 명언 목록** — 한국어 명언이 앱 안에 내장되어 있어 네트워크 없이 동작합니다. (`quotes.js`)
- **라이트/다크 모드** 자동 대응.

## ⚠️ 알림 동작 방식 (중요)

이 앱은 **서버가 없는 정적 사이트**입니다. 따라서 알림은 다음 조건에서 동작합니다.

- ✅ 브라우저(또는 설치된 앱)가 **실행 중일 때** 오전 9시에 알림이 표시됩니다.
- ⚙️ 일부 브라우저(설치형 PWA의 Chrome 등)는 **주기 백그라운드 동기화**를 지원해, 브라우저가 완전히 닫혀 있어도 알림이 오도록 시도합니다. (best-effort, 브라우저·OS에 따라 다름)
- ❌ 모든 앱이 완전히 종료된 상태에서 **100% 보장되는 9시 알림**은 서버 + 웹 푸시(Web Push)가 필요합니다. 이 정적 버전에는 포함되어 있지 않습니다.

일상적으로 아침에 기기를 사용하는 경우에는 정적 버전으로 충분합니다.

## 🚀 실행 방법

정적 파일이므로 로컬 서버로 열면 됩니다. (Service Worker/알림은 `http://localhost` 또는 `https`에서만 동작)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 📦 배포 (GitHub Pages)

1. 이 브랜치를 푸시합니다.
2. GitHub 저장소 **Settings → Pages**에서 브랜치를 소스로 지정합니다.
3. 발급된 `https://<사용자>.github.io/<저장소>/` 주소로 접속합니다.

## 📁 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 |
| `styles.css` | 스타일 (라이트/다크, 애니메이션) |
| `app.js` | 명언 선택, 알림 예약, SW 등록 |
| `quotes.js` | 내장 명언 목록 (여기에 명언을 추가하세요) |
| `sw.js` | Service Worker (오프라인 캐시, 알림, 주기 동기화) |
| `manifest.webmanifest` | PWA 매니페스트 |
| `icon.svg` | 앱 아이콘 |

## ➕ 명언 추가하기

`quotes.js`의 `QUOTES` 배열에 항목을 추가하면 됩니다.

```js
{ text: "명언 내용", author: "지은이" }
```
